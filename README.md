# Green-IT – Caseopgave

ITIL er et rammeværk til at styre og forbedre IT-services med fokus på værdi, stabil drift og løbende forbedringer. Opgaven handler om at bruge ITIL til at analysere Green-ITs IT-drift og understøtte virksomhedens vækst og bæredygtige løsninger gennem SLA'er, risikostyring, Service Value Chain og centrale practices. `notes.html` indeholder studienoter, og `case.pdf` beskriver opgaven.

Kræver, at [Typst](https://typst.app/) er installeret.

```text
// Kompilér til PDF
typst compile green-it-caseopgave.typ

// Kompilér automatisk ved ændringer (stop med Ctrl+C)
typst watch green-it-caseopgave.typ
```
